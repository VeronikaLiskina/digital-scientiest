# Проверка поиска публикаций по названию

В базе есть публикация №55 «МЕЛОВАЯ СИСТЕМА РОССИИ И БЛИЖНЕГО ЗАРУБЕЖЬЯ
ПРОБЛЕМЫ СТРАТИГРАФИИ И ПАЛЕОГЕОГРАФИИ», 2007 год. В присланном пользователем
ответе «меловая» была заменена на «мелкая», после чего модель выдала выдуманное
объяснение на другую тему. Проверки текущего каталога раньше не распознавали
короткое название без команды подбора, а автоматический переход к общим
знаниям позволял модели отвечать без найденной публикации.

Теперь до выбора ветки генерации проверяется настоящее название или его
непрерывный фрагмент. Совпадения сравниваются по целым словам без учёта
регистра, пробелов и пунктуации; похожие слова автоматически не подставляются.
Найденный документ возвращается карточкой с метаданными, ссылкой и выдержкой
из обработанного текста. Этот путь не вызывает API и не загружает модели
эмбеддингов или ранжирования. Правило действует во всех режимах, включая
продолжение после свободного диалога.

Продолжение «О чём она?» сохраняет название. Для прочих коротких уточнений
после ответа из каталога в автоматическом режиме запрещена замена отсутствующих
сведений общими знаниями. В общий системный промпт также добавлено требование
не подменять научные термины похожими словами и уточнять неоднозначный запрос.

В работающем приложении прошли 10 из 10 HTTP-проверок: исходный запрос во
всех трёх режимах, нижний регистр, запрос с кавычками, описание, другое русское
название, английское название, продолжение диалога и отсутствие подмены
«мелкая» на «меловая». Исходный запрос вернул ровно публикацию №55.
Время отдельных запросов — 0,007–0,197 секунды на текущем компьютере.

Набор: `backend/evaluation/title_lookup_cases.json`.
Подробные ответы: `exports/assistant-title-lookup-2026-11-02.json`.
Регрессионные тесты: `backend/tests/test_assistant_title_lookup.py`;
в них вызов любой модели для поиска по известному названию считается ошибкой.
Полный набор тестов backend после исправления: 416 пройдено за 147,79 секунды.
Исправление развёрнуто в Docker; backend и frontend отвечают HTTP 200.

Это исправление маршрутизации и поиска по названиям. Оно не доказывает
отсутствие галлюцинаций во всех ответах из общих знаний или при генерации
ответа по сложному научному вопросу.
