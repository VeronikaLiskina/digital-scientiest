# Вопросы для проверки ассистента по текущей базе

Подготовлено 2 ноября 2026 года по снимку 48 публикаций и 1 847 обработанных фрагментов (2 356 612 символов текста). Просмотрены метаданные всех публикаций, аннотации, вводные и итоговые положения и выбранные фрагменты. Это не построчная экспертиза всего корпуса. Для каждой публикации есть отдельный вопрос по содержанию.

Ниже 100 сценариев: 20 для каталога и названий, 48 по отдельным публикациям, 8 сравнений, 8 цепочек диалога, 8 проверок на выдумки, 4 разговорных и 4 вопроса внутри большого сборника. Сценарии составлены, но ответы ассистента на этот новый набор ещё не оценивались; число вопросов не является показателем точности.

## Как проверять

- Вопросы по содержанию, сравнения и проверки ложных предпосылок задавать в режиме «По публикациям». Для названий и цепочек с `auto` — в режиме «Авто», для свободного разговора — в соответствующем режиме.
- Одиночные вопросы задавать в новых чатах. В цепочках сначала последовательно отправить реплики из строки «До вопроса», затем проверяемую реплику.
- Проверять смысл, объекты, числа, единицы, погрешности и ссылки. Перефразирование допустимо. Для сравнений нужны ссылки на обе работы, если вывод основан на обеих.
- `№` — ID публикации в приложении, `фр.` — ID обработанного фрагмента. Номер страницы в JSON взят из индекса и может отличаться от печатной нумерации.
- 0 — выдумка/неверный объект; 1 — частичный ответ или неполные источники; 2 — фактически верный ответ с достаточным подтверждением. Отказы API и время ответа фиксировать отдельно от качества содержания. Для точных датировок проверять погрешности.

## Особенности источников, которые нельзя принимать за ошибки модели

- №6: название карточки взято из заголовка конференции; фактический материал — о палеоархейских мафитах юго-запада Сибирского кратона.
- №16: файл содержит соседний материал о Жидойском массиве. Раздел `Abstract` может относиться к нему, а не к работе о раннекембрийском магматизме. Источник нужно различать по содержанию.
- №27 и №49 — описания полезных моделей к патентам, а №55 — сборник. Поле типа в карточке не всегда отражает настоящий жанр.
- №34: аннотация даёт интервал 682–792, заключение — 682–778 годы н. э. Правильный ответ на вопрос о расхождении должен сохранить оба значения.
- №38 и №47: в карточках отсутствует год. Не смешивать поиск по полю года с попыткой восстановить дату по тексту.
- №53: в распознанном тексте смешиваются кириллические и латинские похожие буквы; в №40 часть изотопных обозначений повреждена. Это отдельные проверки устойчивости поиска.
- Метки разделов местами неточны: под «Выводами» встречаются библиография или оглавление. Содержание проверяется по самому фрагменту, а не только по его метке.
