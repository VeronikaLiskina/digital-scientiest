чтобы не считать допустимую альтернативную ссылку ошибкой системы.

## Исправления

- Подбор распознаёт вежливые просьбы, фамилию без слова «автор» и основные
  английские формулировки. Уточнения сохраняют ранее заданные фильтры.
- При смешанном языке кандидатов выполняется поиск по переведённому вопросу.
  Предварительные совпадения больше не скрывают англоязычные доказательства.
  Если окончательное ранжирование отвергло совпадения, перевод также остаётся
  возможным. При сбое перевода сохраняются доступные исходные результаты.
- Короткие научные уточнения преобразуются в самостоятельный поисковый вопрос
  с использованием предыдущих вопросов пользователя. Старые ответы ассистента
  не используются как источник фактов.
- Вопрос о возрасте больше не получает общий бонус только за упоминание метода
  датирования: такой бонус предназначен для вопросов именно о методах.
- Повторные пары «вопрос — текст» используют ограниченный кэш оценок ранжирования.
  Сам поиск выполняется заново; новые публикации не скрываются старой выдачей.
- Загрузка моделей вынесена из основного цикла сервера. Одновременные первые
  запросы не создают несколько экземпляров одной поисковой модели.
- Увеличена верхняя граница длины API-ответа с 1 400 до 4 096 токенов. Оборванные
  ответы распознаются; проверки JSON, языка и ссылок сохранены. Диагностические
  исключения не включают тело ошибки провайдера с потенциальным текстом запроса.
- Добавлены инструкции принятой геологической терминологии и сохранения
  вероятностных оговорок источников. Их отдельная повторная проверка сохраняется
  в [дополнительном отчёте](../exports/assistant-terminology-2026-11-01.json).
- Docker ждёт готовности базы и Redis, сервисы автоматически перезапускаются;
  один PDF-воркер и ограничение предварительно взятых задач заданы явно.

Параметры длины и режима JSON сверены с документацией
[Groq API](https://console.groq.com/docs/api-reference) и
[структурированных ответов Groq](https://console.groq.com/docs/structured-outputs).

## Повтор после загрузки новых 50 публикаций

Дождитесь обработки и повторите проверку готовности. Запустите тот же набор,
сохранив новый отчёт; затем добавьте вопросы и ожидаемые источники по новым статьям.
Сравнивайте одни и те же вопросы, отдельно качество, скорость и отсутствие
ложных ответов. Все новые материалы участвуют в следующем поиске без изменения кода.

Команды проверки приведены в [README](../README.md), порядок переноса базы,
файлов и кэша моделей — в [инструкции для ПК института](institute-installation.md).
