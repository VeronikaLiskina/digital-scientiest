# Frontend MVP — «Цифровой учёный»

Очищенный frontend без App.tsx, с роутингом в `src/main.tsx`, SCSS-структурой и исправленными сценариями:

- загрузка PDF через стилизованную кнопку;
- выбор уже загруженного PDF;
- авторы/темы/ключевые слова выбираются через поиск и множественный выбор;
- справочники создаются/редактируются/удаляются из интерфейса;
- списки справочников находятся под формой и сворачиваются;
- исправлена сетка фильтров публикаций;
- с главной удалена лишняя карточка «Добавить публикацию».

## Запуск

```bash
npm install
npm run dev
```

Backend ожидается по адресу:

```env
VITE_API_BASE_URL=http://localhost:8000/api
```
